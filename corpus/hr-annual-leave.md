# 年次有給休暇の取扱い

## 第1章 総則

### 第1条（目的）
この規程は、就業規則第9条にもとづき、社員の年次有給休暇（以下「年休」という）の付与、取得の手続き、繰越および計画付与について定める。

### 第2条（基準日）
年休の付与は、入社日から6か月を経過した日を初回とし、その後は毎年4月1日を基準日として一斉に付与する。初回付与が10月1日から3月31日までの間となった社員は、翌年4月1日に2回目の年休を付与する。

## 第2章 付与日数

### 第3条（付与日数）
基準日の前1年間（初回は入社後6か月間）の出勤率が8割以上の社員に、勤続年数に応じて次の日数を付与する。

| 勤続年数 | 付与日数 |
|---|---|
| 6か月 | 10日 |
| 1年6か月 | 11日 |
| 2年6か月 | 12日 |
| 3年6か月 | 14日 |
| 4年6か月 | 16日 |
| 5年6か月 | 18日 |
| 6年6か月以上 | 20日 |

### 第4条（短時間の社員）
週の所定労働日数が4日以下かつ週30時間未満の社員には、所定労働日数に応じて比例付与する。日数は人事部が個別に通知する。

## 第3章 取得の単位と手続き

### 第5条（半日単位）
年休は半日単位で取得できる。本社の場合、午前休は9:00〜13:00、午後休は14:00〜18:00とし、2回で1日として数える。半日単位の取得回数に上限は設けない。

### 第6条（時間単位）
年休は、1年度につき5日分（40時間）まで1時間単位で取得できる。1時間未満の端数での取得はできない。時間単位で使わなかった分を翌年度に繰り越すときは、日数に換算して繰り越す。

### 第7条（申請期限）
年休は、取得日の3営業日前までに勤怠システムで申請し、所属長の承認を得る。時間単位の年休は前日の終業時刻までに申請する。会社は、事業の正常な運営を妨げる場合に限り、取得日を変更することがある。

### 第8条（急な病気などの場合）
急病などで事前に申請できなかった場合は、当日の始業後1時間以内に所属長へ連絡し、出勤してから3営業日以内に勤怠システムで事後申請する。期限を過ぎた場合は欠勤として扱う。

## 第4章 繰越と積立

### 第9条（繰越）
その年度に使わなかった年休は、翌年度に限り繰り越せる。繰越分を含めて保有できる日数は最大40日とする。取得するときは繰越分から先に使ったものとして扱う。

### 第10条（積立休暇）
繰越期限を過ぎて消滅する年休は、毎年5日を限度として積立休暇に移し、最大60日まで積み立てられる。積立休暇は、本人の私傷病で連続5日以上休む場合、または家族の看護をする場合に使える。

## 第5章 計画付与と取得義務

### 第11条（計画付与）
労使協定にもとづき、各人の年休のうち5日を超える部分について、年3日を計画付与する。原則として夏季休日の前後に2日、年末年始休日の前に1日を充てる。日付は毎年2月末までに会社カレンダーで示す。

### 第12条（年5日の取得）
年10日以上付与される社員は、基準日から1年以内に5日以上取得しなければならない。基準日から6か月を経過した時点で取得が3日未満の社員には、人事部が本人の希望を聞いたうえで取得日を指定する。

### 第13条（問い合わせ）
年休の残日数は勤怠システムの「休暇残高」画面で確認できる。不明な点は人事部 勤怠担当（内線 2210）に問い合わせる。

## 附則
この規程は2026年4月1日から施行する。
