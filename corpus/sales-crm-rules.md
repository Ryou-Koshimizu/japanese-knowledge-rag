# 営業日報・顧客情報の入力ルール

## 1. 基本

### 1.1 目的
このルールは、営業部が使う顧客管理システムへの日報・顧客情報・商談情報の入力方法をそろえ、部内で情報を正しく共有し、売上の見通しを立てられるようにするために定める。

### 1.2 対象
営業部に所属するすべての者（契約社員・派遣社員を含む）に適用する。顧客管理システムの操作方法は、社内ポータルの操作マニュアル（https://portal.soranome.example/sales/crm-manual）を参照する。

## 2. 営業日報

### 2.1 締め
日報は、その日の業務の終わりまでに入力する。直行直帰や出張などで当日に入力できなかった場合は、翌営業日の午前10時までに入力する。期限を過ぎた日報は、システム上「遅延」と表示される。

### 2.2 書く内容
訪問、オンライン商談、5分以上の電話を記録の対象とする。1件ごとに次の項目を書く。
- 相手の会社名と部署・役職
- 目的と結果
- 次のアクションとその期日

### 2.3 上長の確認
営業課長は、部下の日報を翌営業日中に確認し、コメントを残す。毎週金曜日には、課ごとに日報をもとにした週次の振り返りを行う。

## 3. 顧客情報の入力

### 3.1 必須項目
| 項目 | 入力のルール |
|---|---|
| 会社名 | 正式名称で、「株式会社」などの法人格を略さない |
| 業種コード | システムの選択肢から1つ選ぶ |
| 所在地 | 都道府県から番地まで |
| 代表電話 | 半角数字とハイフン |
| 担当者 | 部署・役職・氏名 |
| 取引区分 | 見込み・取引中・休眠のいずれか |
| 情報源 | 展示会・紹介・問い合わせ・既存顧客など |

### 3.2 重複の防止
新しい会社を登録する前に、会社名と代表電話で検索し、すでに登録がないかを確かめる。重複を見つけた場合は自分で削除せず、営業企画グループ（内線 4320）へ統合を依頼する。

### 3.3 名刺と個人情報
受け取った名刺は、受け取った日から3営業日以内にスキャンして顧客管理システムへ登録する。名刺の原本の扱いは文書管理規程に、個人情報の扱い全般は個人情報取扱規程による。

### 3.4 情報の更新
顧客の担当者の異動・退職を知った場合は、5営業日以内に担当者の情報を更新する。

## 4. 商談ステージ

### 4.1 ステージの定義
商談には、次のステージと受注確度を設定する。
| ステージ | 状態 | 受注確度 |
|---|---|---|
| A 案件化 | ニーズを確認した。予算や時期は未定 | 10% |
| B 要件確認 | 仕様・台数・予算を確認した | 25% |
| C 見積提示 | 正式な見積を提出した | 45% |
| D 内示 | 発注の内示を受け、購買の手続き中 | 75% |
| E 受注 | 注文書を受け取った | 100% |
| X 失注 | 失注が確定した | 0% |

### 4.2 ステージの更新
ステージが変わった日から2営業日以内に更新する。受注予定日を過ぎたまま30日間更新がない商談には、システムが「要確認」の印を付ける。

### 4.3 売上の見通し
毎週月曜日の12時時点のデータで、商談金額に受注確度を掛けた額を集計し、営業部長へ報告する。

### 4.4 失注したとき
失注理由を「価格・仕様・納期・競合・予算消滅・その他」から必ず1つ選び、「その他」を選んだ場合は内容を書く。
