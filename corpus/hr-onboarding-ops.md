# 入社手続きマニュアル（人事部用）

## 1. このマニュアルについて

### 1.1 目的と対象
本マニュアルは、正社員・契約社員の入社手続きを人事部の担当者が漏れなく進めるための作業手順を定める。パート・アルバイトの入社も本マニュアルを準用し、社会保険の加入要否のみ個別に判断する。担当者は入社者ごとに「入社手続きチェックリスト（様式HR-07）」を作成し、各作業の完了日を記入する。

### 1.2 担当と役割
- 主担当：人事部 労務グループの担当者（入社者1名につき1名を割り当てる）
- 確認者：労務グループのリーダー（チェックリストの最終確認）
- 関係部署：配属先の所属長、情報システム部、総務担当

入社予定者からの問い合わせ窓口は人事部 労務グループ（内線 4210、hr-onboarding@soranome.example）とする。

## 2. 入社前の手続き

### 2.1 内定承諾後の連絡
内定承諾書を受領したら、受領日から2営業日以内に入社予定者へ「入社書類のご案内」をメールで送る。案内には提出書類の一覧、提出方法、提出期限を記載する。入社書類の提出期限は、入社日の10営業日前とする。

### 2.2 回収する書類
| 書類 | 原本/写し | 備考 |
|---|---|---|
| 雇用契約書（2部に署名） | 原本 | 1部は本人控え |
| 身元保証書 | 原本 | 保証人1名の署名・押印 |
| 個人番号（マイナンバー）の確認書類 | 写し | 扶養家族の分を含む |
| 基礎年金番号がわかる書類 | 写し | |
| 雇用保険被保険者証 | 写し | 前職がある場合のみ |
| 源泉徴収票（前職分） | 原本 | 入社年に前職の収入がある場合 |
| 給与振込口座の届出書 | 原本 | 本人名義の口座に限る |
| 扶養控除等（異動）申告書 | 原本 | |
| 通勤経路の届出書 | 原本 | 手当の額は通勤手当規程による |

個人番号の確認書類はメールで受け取らない。本人には社内ポータルの書類提出フォーム（https://portal.soranome.example/hr/onboarding）からアップロードしてもらい、紙で受け取った場合は人事部の施錠キャビネット（第2書庫）でのみ保管する。

### 2.3 期限までに書類がそろわないとき
提出期限を過ぎて未提出の書類がある場合は、翌営業日に本人へ電話で催促し、チェックリストに記録する。入社日の5営業日前になっても源泉徴収票以外の書類がそろわない場合は、労務グループのリーダーに報告し、配属先の所属長と入社日の扱いを協議する。源泉徴収票は年末調整までに提出されればよい。

### 2.4 社内への事前依頼
入社日の15営業日前までに、次の依頼をワークフローシステムで起票する。
- 情報システム部：アカウントとPCの準備（作業の詳細は情報システム部の手順による）
- 総務担当：社員証、名刺、ロッカー、作業服（工場配属の場合）
- 配属先の所属長：初日の受け入れ担当者（メンター）1名の指名

## 3. 社会保険・労働保険の手続き

### 3.1 健康保険・厚生年金
資格取得届は、入社日の翌々営業日までに電子申請で提出する。これは法定の期限より前倒しした社内期限である。被扶養者がいる場合は、被扶養者（異動）届を同時に提出する。

### 3.2 雇用保険
雇用保険の資格取得届は、入社月の翌月5日までに提出する。前職の被保険者番号が不明な場合は、本人に確認したうえで番号なしで届け出る。

### 3.3 提出後の確認
提出した届出の控えは、労務システムの社員ファイルにPDFで保存する。確認者は、毎月第1営業日に前月入社者全員の届出控えがそろっているかを点検する。

## 4. 入社初日の段取り

### 4.1 当日の流れ
| 時刻 | 内容 | 担当 |
|---|---|---|
| 9:30 | 本社1階受付に集合 | 人事部 |
| 9:45〜11:15 | 入社オリエンテーション（会社概要・規程の説明） | 人事部 |
| 11:15〜12:00 | PCの受け取り・初回ログイン | 情報システム部 |
| 13:00〜 | 配属先での紹介・業務説明 | 所属長・メンター |

上記の集合時刻は初日だけの扱いであり、2日目以降の勤務時間は就業規則による。工場配属者は午後に工場へ移動し、安全衛生教育（90分）を受ける。

### 4.2 当日渡すもの・回収するもの
社員証、入社案内冊子、貸与品の受領書を渡す。貸与品の受領書は本人の署名を得て、その日のうちに回収する。

### 4.3 入社後のフォロー
入社から1か月後に人事部の担当者が30分の面談を行い、結果をチェックリストに記録する。チェックリストは面談の記録をもって完了とし、労務グループのリーダーの確認を受けて保管する。
