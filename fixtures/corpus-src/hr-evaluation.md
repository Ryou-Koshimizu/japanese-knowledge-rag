# 人事評価の運用手引き（評価者向け）

## 1. この手引きについて

### 1.1 目的
この手引きは、評価者が人事評価を公平かつ一貫した方法で行うための運用ルールを定める。対象は課長以上の管理職で、部下を持つ者は全員が評価者研修（年1回）を受講したうえで評価を行う。

### 1.2 評価者の区分
- 一次評価者：直属の課長（課長がいない場合は部長）
- 二次評価者：部長
- 最終調整：評価調整会議（各部長と人事部長で構成し、人事部が事務局を務める）

一次評価者と二次評価者の評価が2段階以上離れた場合は、二次評価者が一次評価者と面談して理由を確認し、その記録を残す。

## 2. 評価の期間とスケジュール

### 2.1 評価期間
評価は年2回行う。上期は4月1日から9月30日まで、下期は10月1日から3月31日までを評価期間とする。期中に異動した者は、在籍期間の長い部署の評価者が評価し、もう一方の部署の評価者から所見を聞く。評価期間中の在籍が3か月未満の者は評価対象外とし、扱いは人事部が個別に決める。

### 2.2 年間スケジュール
| 時期 | 作業 | 担当 |
|---|---|---|
| 期首から3週間以内 | 目標設定面談・目標シートの登録 | 本人・一次評価者 |
| 7月・1月 | 中間面談 | 一次評価者 |
| 期末翌月の10日まで | 自己評価の入力 | 本人 |
| 期末翌月の20日まで | 一次評価の入力 | 一次評価者 |
| 期末翌月の末日まで | 二次評価の入力 | 二次評価者 |
| 期末の翌々月の第2週 | 評価調整会議 | 各部長・人事部長 |
| 調整会議後10営業日以内 | フィードバック面談 | 一次評価者 |

入力はすべてワークフローシステムの「人事評価」画面で行う。

## 3. 評価の段階と基準

### 3.1 評価項目とウエイト
評価は、目標の達成度を見る「成果評価」と、行動指針に沿った行動を見る「行動評価」で構成する。ウエイトは、一般社員が成果50%・行動50%、管理職が成果70%・行動30%とする。

### 3.2 評価段階
| 段階 | 基準 |
|---|---|
| S | 目標を大きく上回り、部門の業績に顕著な貢献をした（達成度120%以上が目安） |
| A | 目標を上回った（達成度105%以上が目安） |
| B | 目標をおおむね達成した |
| C | 目標に届かず、一部に指導を要した（達成度90%未満が目安） |
| D | 目標を大きく下回り、継続的な指導を要した |

### 3.3 評価の分布の目安
部門ごとの評価の分布は、次の目安に照らして確認する。
| S | A | B | C | D |
|---|---|---|---|---|
| 6% | 22% | 52% | 15% | 5% |

SとAの合計は、部門の評価対象者の28%以内とする。評価対象者が10名未満の部門は、本部単位で合算して目安と照らす。目安を超える場合、二次評価者は評価調整会議で理由を説明する。

## 4. 面談の進め方

### 4.1 目標設定面談
面談は1人30分以上を確保する。目標は3〜5個とし、期限と達成の基準を数字で書けるものにする。

### 4.2 中間面談
進み具合を確認し、目標の前提が大きく変わった場合は目標シートを修正する。修正は一次評価者の承認をもって確定する。

### 4.3 フィードバック面談
評価結果と、その根拠となった具体的な事実を伝え、次期の目標の方向をすり合わせる。面談は45分以上を目安とし、面談の記録は実施から3営業日以内にワークフローシステムへ登録する。

## 5. 評価者の注意事項

### 5.1 評価エラーの防止
一つの印象で全体を評価する（ハロー効果）、甘く付ける（寛大化）、真ん中に寄せる（中心化）、期末の出来事だけで判断する（期末効果）に注意する。評価は評価期間中の事実のみにもとづいて行う。

### 5.2 異議申し立て
本人は、フィードバック面談の日から14日以内に人事部へ異議を申し立てることができる。人事部は受付から30日以内に再確認の結果を本人と評価者に回答する。

### 5.3 評価結果の取扱い
評価結果は、本人・評価者・人事部以外に開示しない。評価結果の昇給・賞与への反映は、人事部の給与・賞与の計算手順および賃金規程による。
