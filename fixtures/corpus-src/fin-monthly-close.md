# 月次決算の手順書

## 1. 概要

### 1.1 目的
本手順書は、経理部が毎月の決算を締め、月次の損益と財政状態を経営会議に報告するまでの作業手順を定める。月次決算は年度決算の土台となるため、各担当は本書のスケジュールと処理基準を守る。

### 1.2 担当
- 売上・債権担当：売上の確定、売掛金の消込、入金遅延の管理
- 仕入・債務担当：仕入・外注費の計上、未払金の確定
- 固定資産担当：減価償却、前払費用の振替
- 取りまとめ担当：引当金の計上、試算表と月次報告書の作成

## 2. 締めスケジュール

### 2.1 標準スケジュール
営業日は、締める月の翌月の営業日で数える。
| 時期 | 作業 |
|---|---|
| 第1営業日 | 各部署からの請求書の回付締切（12時）・経費精算データの取り込み |
| 第2営業日 | 売上の確定（出荷データとの照合） |
| 第3営業日 | 売掛金の消込・入金遅延一覧の作成 |
| 第4営業日 | 減価償却・引当金・前払費用の振替 |
| 第5営業日 | 仮締め・試算表の作成 |
| 第6営業日 | 経理部長のレビューと修正 |
| 第7営業日 | 本締め・月次報告書を経営企画室へ提出 |

経費精算そのものの申請期限は経費精算規程による。

### 2.2 計上が間に合わないとき
請求書が届かないなど期限までに確定できない取引は、見積額で計上し、翌月に差額を調整する。1件50万円以上の見積計上は、経理部長の承認を得る。

### 2.3 四半期末・年度末
6月・9月・12月・3月の締めは、第5営業日以降の各作業を2営業日ずつ後ろにずらす。

## 3. 売掛金の消込

### 3.1 入金データの取り込み
入金明細は毎営業日10時に取り込む。取り込んだ明細は、その日のうちに消込の作業を始める。

### 3.2 消込の方法
入金は請求書番号で照合する。請求書番号で一致しない入金は、取引先名と金額で候補を探し、それでも特定できない入金は3営業日以内に営業担当へ確認する。確認が取れるまでは仮受金として処理する。

### 3.3 差額の処理
取引先が振込手数料を差し引いて入金したことによる差額が880円以下の場合は、支払手数料として処理する。880円を超える差額は、営業担当を通じて取引先に確認し、翌月の請求に加えるか、取引先に別途振り込んでもらう。

### 3.4 入金遅延のフォロー
支払期日を過ぎても入金がない売掛金は、第3営業日に「入金遅延一覧」にまとめて営業部長へ送る。支払期日から60日を超えた売掛金は、経理部長と営業部長で回収の方針を決め、その結果を一覧に記録する。

## 4. 引当金の計上

### 4.1 貸倒引当金
通常の売掛金には、過去3年間の貸倒実績率の平均を掛けて引当金を計上する。支払期日を過ぎた売掛金は、次の率で個別に計上する。
| 支払期日からの経過 | 引当率 |
|---|---|
| 91日〜180日 | 25% |
| 181日以上 | 60% |
| 取引先の法的整理の申立て | 100% |

### 4.2 賞与引当金
次回の賞与の支給見込額を算定期間の月数で割り、毎月の分を計上する。支給見込額は、人事部から毎月第2営業日までに受け取る。

### 4.3 製品保証引当金
当月の製品売上高の0.4%を製品保証引当金として計上し、保証修理の実績が出た月に取り崩す。

## 5. 月次報告

### 5.1 報告書の内容
月次報告書には、損益計算書、貸借対照表、予算との差異を載せる。予算との差異が10%以上かつ300万円以上の科目は、差異の理由を必ずコメントする。

### 5.2 提出と報告
月次報告書はワークフローシステムで経営企画室へ提出する。経理部長は、提出後に開かれる経営会議で内容を報告する。
