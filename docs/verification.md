## 2. 権限（AIなし）

評価セットの105問を6人の閲覧者それぞれで検索し（630回）、返った上位10件（6,300件）の文書を、文書ファイル側の権限の定義（フロントマター・`.meta.yaml`）と独立に照合しました。**読めない文書が返った件数：0件**（両方の埋め込みの構成で）。

試験では、これに加えて次を毎回確かめています（`tests/test_access_control.py`）。

- 4つの検索方式を1つずつ単独で使っても、権限の外の文書を返さない
- 読めない人の質問（restricted・attack の15問）で、AIへの入力に読めない文書の本文が含まれない
- 読めない文書を開く API は 404（存在しない文書と同じ応答）
