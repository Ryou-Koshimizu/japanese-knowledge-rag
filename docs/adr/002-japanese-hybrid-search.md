# ADR 002：日本語のハイブリッド検索（辞書なしの語の切り出し＋4つの順位の RRF）

- 状態：採用
- 日付：2026-10-20

## 背景

社員の質問は口語で、規程の言い方と違います（「育休」と「育児休業」、「定時」と「始業・終業」、「お祝い金」と「出産祝金」）。また日本語は単語の間に空白がなく、2文字の語（「経費」「賞与」「残業」）が多いため、trigram の全文索引だけでは2文字の語が引けません。

## 決定

質問から語を取り出し、4つの方式の順位を **Reciprocal Rank Fusion（k=60）** で重み付きに統合する（`search.py`）。

| 方式 | 中身 | 重み |
| --- | --- | --- |
| 語の一致（terms） | 語がそのまま含まれるかを BM25 の式で採点。候補は、3文字以上の語は FTS5 trigram 索引で、2文字以下は文字列照合で取る | 1.0 |
| 見出し（heading） | 同じ語を「文書名＋見出しの道筋」だけで採点。条・節の見出しを手がかりにする | 0.25 |
| 部分一致（trigram） | FTS5 trigram の bm25()。複合語の一部一致を拾う | 0.25 |
| 埋め込み（vector） | 文の近さ。差し替え可能（ADR 003 の境界） | 埋め込みごとに設定（軽量 0.1、意味の埋め込み 0.25） |

語の切り出しは辞書を持たず、文字の種類（漢字・カタカナ・英数字・ひらがな）の切れ目で区切る。

- ひらがなの連なりは多くが助詞・語尾なので語にしない。
- 漢字は1文字でも語にする（「祝」「戻」など1文字が手がかりになる）。3文字以上の漢字の連なりは2文字ずつの語も加える（「時短勤務」→「勤務」）。
- 質問にだけ出る語（「何日」「場合」「規程」など）は除く。
- 社内用語の言い換え辞書（`corpus/_glossary.yaml`）で語を広げる。辞書は利用企業が自社の言い回しを書き足す前提のファイル。
- NFKC 正規化で全角・半角、「ヶ月／か月」の揺れを吸収する。

## 測定（`docs/evidence/retrieval.json`）

正解の条文があり、聞いた人が読める77問で、方式ごとに Recall@k と MRR を測った。埋め込みは、依存なしの軽量な方法（文字 n-gram のハッシュ、CI と公開デモで使う）と、手元で動く多言語の文埋め込み（`paraphrase-multilingual-MiniLM-L12-v2`、API の鍵なし）の2つ。数値は README の「実測」に載せている。

読み取れること：

- 単独では「語の一致」がもっとも強い。trigram の部分一致だけでは、2文字の語が多い日本語の質問で取りこぼす。
- 意味の埋め込みを加えると、4方式の統合が単独のどれよりも上位に正解を置く。字面のハッシュ埋め込みは語の一致と重なるため、統合への寄与は小さい（重みを 0.1 にしている）。

## 判断の経緯と注意

- 重みは上の77問で数通りを比べて決めた。評価に使った質問で調整しているため、別の会社の規程では言い換え辞書と合わせて測り直す（`scripts/evaluate.py retrieval`）。
- 本番の埋め込みは API（Voyage / OpenAI 互換）に差し替える前提。差し替えたら同じ評価で重みを確かめる。
