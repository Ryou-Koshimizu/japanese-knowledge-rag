# ADR 006：公開デモは実AIの記録を再生する

- 状態：採用
- 日付：2026-10-20

## 決定

- 公開デモは鍵なしで動かす。検索はその場で実行し、回答は **実AI（測定に使った gpt-6.1-sol）で事前に記録した回答** を再生する。
- 画面には「記録の再生」の印と、記録したモデル・日付を出す。記録にない質問には、その旨と記録済みの質問の一覧、その場の検索結果を出す（回答を作り出さない）。
- 記録は評価の実行（`scripts/evaluate.py answers`）がそのまま書く `eval/recordings.json`。再生でも、記録した資料を権限で引き直し、本文と一字一句照合してから表示する。
- 試験 `test_recorded_answers_still_pass_with_current_code` が、記録を今のコードで採点し直し、全問が正しいことを毎回確かめる。

## 配置

- Vercel の Python ランタイムで `api/index.py`（FastAPI）を動かす。規程集は起動時にメモリ上の SQLite へ取り込む（PDF・Word を含む32文書で、このMac〔Apple シリコン〕では読み込みを含め1.4〜1.7秒）。
- 公開デモの埋め込みは依存なしの軽量な方法。多言語の埋め込みモデル（約220MB）は関数の容量に入れない。
