# 脅威と対策

| 脅威 | 対策 | 確かめ方 |
| --- | --- | --- |
| 他部署・上位役職の文書が回答に混ざる | 検索のすべての SQL に権限の条件。AIへの入力・文書の閲覧も同じ条件（ADR 005） | 全質問×全閲覧者の照合、AIへの入力の検査 |
| 文書に書き込まれた命令（間接的なプロンプトインジェクション） | 資料を乱数名のタグで囲みデータとして渡す、指示文で命令に従わないと明示、引用の照合、根拠にない URL の除去（ADR 004） | 評価セットの injection、`tests/test_answer.py` |
| 質問からの乗っ取り（役割の書き換え・指示文の開示要求） | 同上。読めない文書はそもそも AI に渡らない | 評価セットの attack |
| それらしい嘘（捏造） | 引用を本文と一字一句照合し、根拠が残らない回答は「記載がありません」に置き換える | 評価の「誤った引用」、単体試験 |
| 画面への不正なスクリプト（XSS） | 文字はすべて `textContent` で入れる。CSP で外部・インラインのスクリプトを禁止（`script-src 'self'`）、`frame-ancestors 'none'` | `tests/test_api.py`、実ブラウザ試験で CSP 違反のコンソールエラー0 |
| 大量の質問による費用の増加 | 実運用モードで利用者ごとに1分あたりの回数を制限（`RAG_ASK_PER_MINUTE`）、質問は400文字まで | `tests/test_api.py` |
| 鍵の漏えい | 鍵は環境変数だけで受け取り、リポジトリに置かない（`.env` は `.gitignore`）。利用者のトークンは SHA-256 のハッシュだけを保存し、比較は定数時間 | `tests/test_api.py` |
| 測定用 Codex の暴走 | 読み取り専用のサンドボックス、シェル・ウェブ検索・画像などの道具をすべて停止、利用者の設定を読まない、渡す環境変数を限定 | `tests/test_providers.py`（偽の codex で引数を検査） |
| 壊れた文書で索引が消える | 読めなかったファイルの文書は削除せず前の索引を残す。取り込みは1トランザクション | `tests/test_ingest_and_search.py` |
| 依存関係・CI の改ざん | GitHub Actions は GitHub 製のみ・コミット SHA で固定・最小権限。CodeQL（Python・JavaScript・Actions）、Dependabot（14日の様子見）、依存関係の審査 | `.github/` |

## 公開デモについて

- AIは呼ばない（記録の再生）。鍵は不要で、外部への送信は Google Fonts の読み込みだけ。
- 規程・会社・人物はすべて架空。メールアドレスは `example` ドメイン、電話は内線番号だけ。
